How this page is built, and how it treats the district's website

Where the dates come from

  1. Read the nav menu on the usd489.com homepage and pick the district calendar link — currently the district calendar.
  2. Follow it to the PDF the district hosts on Thrillshare, and check it really is a PDF.
  3. Parse the legend column down the right of the PDF — the “17-NO SCHOOL Teacher Inservice” list — not the month grids, where the meaning is carried only by colour.
  4. Expand date ranges into individual days. Nothing is typed in by hand, so a refresh picks up whatever the district changed.

How it stays a good citizen of usd489.com

  • It obeys robots.txt. The district allows crawling of / for every agent and disallows only /api/. This reads exactly one page — the homepage — and never touches /api/.
  • It identifies itself honestly. Requests are sent as usd489-calendar-bot/1.0, not disguised as a browser or a search engine. The site is behind a bot challenge that turns away anything claiming to be a browser; rather than working around that by impersonating Chrome, this asks for the content as what it actually is, which is the path the district's own robots.txt permits.
  • It almost never asks. Loading this page sends zero requests to usd489.com — you're reading a cached copy. The district's site is contacted only when an admin presses Refresh on the admin page: no polling, no timer, no fetch per visitor. A school calendar is published once and rarely changes, so in practice that's a couple of requests a year.
  • Two requests per refresh, one at a time. A refresh fetches the homepage and then the PDF — nothing else, no spidering of other pages. Concurrent refreshes are locked out and a minimum interval is enforced, so repeated clicking can't pile requests onto the site.
  • It never republishes their file. The PDF isn't mirrored here; the link above points at the district's own copy, so they stay the source of record.

This is an unofficial personal project and not affiliated with or endorsed by Hays USD 489. The district's PDF is always authoritative — if something here disagrees with it, trust the PDF.
