How this page is built, and how it treats the district's website

Where the dates come from

  1. Fetch the usd489.com homepage and read the site's own navigation menu, which is embedded in the page as JSON.
  2. Pick the nav entry that looks like the district calendar — preferring one named “district” with the latest school year, and skipping the BOE meeting calendar. It currently resolves that link.
  3. Follow it to the calendar PDF the district hosts on Thrillshare, and confirm the response really is a PDF.
  4. Read the legend column down the right-hand side of the PDF — the “17-NO SCHOOL Teacher Inservice” list — rather than the month grids. The legend is plain text in reading order; the grids are bare day numbers whose meaning is carried only by colour fill, so they'd break far more easily.
  5. Expand day ranges into individual dates, sort them, and hand the result to this page as JSON. Nothing here is typed in by hand — if the district changes the PDF, a refresh picks it up.

How it stays a good citizen of usd489.com

  • It obeys robots.txt. The district allows crawling of / for every agent and disallows only /api/. This reads exactly one page — the homepage — and never touches /api/.
  • It identifies itself honestly. Requests are sent as usd489-calendar-bot/1.0, not disguised as a browser or a search engine. The site is behind a bot challenge that turns away anything claiming to be a browser; rather than working around that by impersonating Chrome, this asks for the content as what it actually is, which is the path the district's own robots.txt permits.
  • It almost never asks. Loading this page sends zero requests to usd489.com — you're reading a cached copy. The district's site is contacted only when someone presses Refresh: no polling, no timer, no fetch per visitor. A school calendar is published once and rarely changes, so in practice that's a couple of requests a year.
  • Two requests per refresh, one at a time. A refresh fetches the homepage and then the PDF — nothing else, no spidering of other pages. Concurrent refreshes are locked out, so repeated clicking can't pile requests onto the site.
  • It never republishes their file. The PDF isn't mirrored here; the link above points at the district's own copy, so they stay the source of record.

This is an unofficial personal project and not affiliated with or endorsed by Hays USD 489. The district's PDF is always authoritative — if something here disagrees with it, trust the PDF.
